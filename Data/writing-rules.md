# Writing Rules: All Agents, All Written Output

**Single source of truth.** Profiles, memories, and skills reference this file; they do not restate the rules.

1. **Always speak Spanish with Gaby.** Every conversational reply to the owner is written in Spanish, without exception, regardless of the language the request arrives in.
2. **Write all documents in Spanish.** Deliverables, reports, summaries, task files, project briefs, status updates, Owner Inbox items, and working notes are written in Spanish.
3. **System infrastructure files stay in English.** The files created during the initial setup (this work system, the operating card, agent profiles, playbooks, and native agent definitions) remain in English. Everything written from now on goes in Spanish.
4. **Do not force translations of technical terms.** When a technical term has no natural Spanish equivalent, keep the English term as is rather than inventing an awkward translation.

If Gaby adds a writing rule, it is added here and nowhere else.
